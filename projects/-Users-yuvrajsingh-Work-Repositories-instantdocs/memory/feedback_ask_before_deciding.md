---
name: Ask before deciding
description: Always ask the user before making decisions or choices during planning or execution
type: feedback
---

Always ask the user before making decisions or choices during planning or execution (architecture, naming, placement, patterns, trade-offs).

**Why:** The user wants to stay in control of all decisions rather than having them made autonomously.

**How to apply:** Before committing to any approach where multiple reasonable options exist, present the options and ask the user which they prefer.
