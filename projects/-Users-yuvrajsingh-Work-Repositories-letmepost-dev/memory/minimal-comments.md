Write minimal code comments. Only comment when it genuinely adds value (non-obvious why, a gotcha, a constraint). When a comment is warranted, keep it short and to the point — no multi-line explanations of self-evident code.

**Why:** The user prefers lean code and verbose comments read as AI-generated. Relates to [[no-ai-attribution]].

**How to apply:** Default to no comment. Match the surrounding file's comment density. Trim any explanatory prose to one terse line.
