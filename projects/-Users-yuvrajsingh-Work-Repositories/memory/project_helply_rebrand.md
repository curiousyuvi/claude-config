(2) electron-store v10 is ESM-only; the CJS webpack main bundle must load it via `await import(/* webpackIgnore: true */ 'electron-store')` (else `store` is null → no auth tokens → stuck on login) and electron-store must be in `release/app/package.json` deps for packaging. (3) Dev login: `instantdocs://` deep-link is hijacked by an installed `/Applications/InstantDocs.app`; backend auth is cookie-based (header-only → 401), tokens map to `__Host-next-auth.csrf-token`/`__Secure-next-auth.session-token` cookies; can seed `~/Library/Application Support/instant-docs/config.json` directly. CORS preflight from localhost:1212 is allowed by the API (ACAO *).
