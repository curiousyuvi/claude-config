**Gotchas:**
- Web vitest env is `node` with no CSS handling; `@platejs/math` imports katex `.css` at module load, so any test importing `kb-blocks` failed to load. Fixed by inlining `@platejs/math` in `apps/web/vitest.config.ts` (`test.server.deps.inline`). Was already broken on the branch.
- NEVER put a `text` string prop on a custom element node: Slate classifies any node with `text` as a text LEAF, not an element, so the editor inserts plain text and never renders it via the node's component (backend serializeHtml keys off `children` so it misleadingly looked fine). The Button label had to be renamed `text`→`label`. Applies to every custom node — store labels/props under non-reserved keys (not `text`/`children`/`type`).
