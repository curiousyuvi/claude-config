Building a custom homepage for the published KB (feature parity with the sibling `instantdocs` project, but richer). **Decided design (owner-directed):** the custom homepage is a **PlateJS document served at the KB root**, NOT a typed section-config system — because instantdocs' "sections with cards" map onto axis's existing Plate card blocks (`kb_card_group`/`kb_card`, `column_group`/`column`). **Manual card curation is the model** (like instantdocs), plus the full article-editor block palette. Manual curation ⇒ **zero new Plate nodes, zero renderer changes** (auto blocks like all-collections-grid/latest-articles would each cost 6 places + a read-time resolver — deferred).

Architecture = reuse the article lifecycle end-to-end:
- **Storage:** new `KbHomepageVariant` entity (one row per `(knowledgeBase, locale)`, KB is parent like `Article`→`ArticleVariant`), in `knowledge-base/domain/entities/`. Columns mirror `ArticleVariant`: `content` (draft Plate JSON), `publishedContent`, `html` (baked), `publishedAt` (per-locale live gate), `hasUnpublishedChanges`, `textVersion` (OCC), `translationStatus`.
- **Enable/disable toggle:** `KbSettings.homepage.mode` (`HomepageMode` as-const: `default`|`custom`) on `KnowledgeBase.settings` (rides `settingsVersion` OCC, read fresh each request). Match instantdocs' 3 UI surfaces: Switch in Customize preferences, Default/Custom control (default-locale-only), and "Enable Custom Homepage" empty-state card.
- **Publish/bake:** copy `ArticlePublishingService.publish` → `KbLinkResolverService.resolve` then `PlateHtmlRenderer.render` (normalize→serialize→sanitize) → store `html`, emit `KB_HOMEPAGE_PUBLISHED`.
- **Serve:** `KbReaderService.home()` gates on `mode===custom` + published default-locale homepage, loads baked `html` (tag-cached like `loadArticleContent`), runs `rewriteConnectedCards`, `homeBody()` emits `kb-prose` div in existing chrome; else falls back to current tree/featured projection (coexist).
- **Freshness:** connected cards self-heal at read time (no re-bake on target rename/move); only editing+publishing the homepage re-bakes.
- **Editor:** reuse `KbArticleEditorShell` + identical `kbEditorPlugins` (invariant — divergent plugins ⇒ renderer silently drops nodes) + `useVariantAutosave` (OCC PUT) + `KbPublishControl`. Localization via variant model + `plate-translate.ts` (content-agnostic).

**Finalized v1 scope (owner-confirmed):** only the single "Custom Homepage" enable toggle ports from instantdocs (the other Layout→Preferences switches — Show items preview, Copy Link, TOC — are NOT part of this feature; Show items preview belongs to the default/normal homepage). Localization is **full per-locale + AI translation from day one** (reuse variant model + `plate-translate.ts` + async worker). Branch: `ys/feat/kb-custom-homepage`.
